Remove an instance configuration. The stored credential of the instance is kept, so clear it separately with 'agh-cli instance credentials clear'.

### Usage

```bash
agh-cli instance remove <name>
```

### Global Options

| Flag | Short | Default | Type | Description |
|------|-------|---------|------|-------------|
| `--config` | `-c` | "" | string | Path to config file |
